# Ramanujan original-source mining run

Created: 2026-05-24T09:38:59.666936+00:00

This folder is a best-effort local working corpus for mining Ramanujan's original-source material. It contains:

- `pdfs/notebooks/`: four notebook/lost-notebook facsimile PDFs.
- `scans_pages/`: extracted page images from the notebook PDFs; 1149 files total.
- `pdfs/published/`: 37 published-paper PDFs.
- `text/`: `pdftotext` output for the published papers.
- `manifests/`: source inventory, checksums, and run summary.
- `experiments/`: first toy computations inspired by the mining pass.
- `diary.md` and `mining_report.md`: disciplined notes, hypotheses, and SOTA comparison.

## Important scope note

This is not a claim to have captured every physical page Ramanujan ever wrote. It captures the known public notebook facsimiles and published papers from the online Ramanujan corpus, and it inventories Trinity College digital-manuscript links. Trinity's high-resolution Wren/UV originals should be the next target for a fuller archival mirror.
